# TCPRC-client

> **Deprecated:** This repository is no longer maintained. Please use [YonderRC](https://github.com/TechnikWeber/YonderRC) instead.

Windows client that reads a gamepad or joystick and sends the inputs over TCP to [TCPRC-server](https://github.com/TechnikWeber/TCPRC-server), like an RC transmitter over TCP.
